# Lemontaste

App lịch làm việc & Stundenzettel cho Lemontaste, tạo từ Khang-Ngon-Restaurant, Git repo độc lập.

## Chạy

```sh
npm ci
npm run dev
npm run build
npm test
```

Mật khẩu ban đầu: `1991`. Dữ liệu lưu cục bộ. Muốn đồng bộ cần cấu hình Supabase riêng theo supabase/schema.sql.

## Dữ liệu

9 nhân viên, 766,39 h, 13.090 € Brutto (bảng của chủ). Mở 11:00–21:30 mỗi ngày; cao điểm 12–14, 18–20; ít khách 15–17; đông thứ 7/CN. Pause 30 phút. Vollzeit 6 giờ/ngày. Nhân viên mới B 150 h, 5 ngày/tuần.
Không tính Nacht-/Sonntagszuschlag. PDF: tờ thông số trước mỗi Stundenzettel, Gesamtstunden để trống cho chủ tự điền.
